# Tic Tac Toe ❌⭕

Tic Tac Toe is a classic two-player web-based game built using modern web technologies. The application provides an interactive and responsive interface where players can compete in real time on the same device.

The project demonstrates core frontend development concepts including DOM manipulation, game logic implementation, and responsive design.

## How to Play

* The game is played between two players
* Player 1 uses X and Player 2 uses O
* Players take turns clicking on the grid
* The first player to align three symbols wins
* If all cells are filled without a winner, the game ends in a draw
